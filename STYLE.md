# ParovGrad — руководство по визуальному стилю

**Стиль:** «Стимпанк-газета». Лист, диалог или сообщение чата выглядит как полоса газеты конца XIX века
(состаренная бумага, чёрная краска, узкие заголовки, газетные линейки, плашки «ЭКСТРА!»).
Металл стимпанка (латунь, медь, воронёное железо, заклёпки) используется только в «механике»
интерфейса: шапка окна, кнопки, шкалы, печать.

Это основной стиль системы. Новые листы, окна, диалоги и карточки чата делаются по этому документу.

Референсы: страницы газет из 4 приложенных изображений (шапка с плашками EXTRA!, колонки с линейками,
узкие заголовки, текст с засечками) и лист персонажа `MLM_SS_merged 2.pdf` (логотип «Паров-Град»
в древнерусском духе, рубрики капителью, линейки, счётчики-кружки).

---

## 1. Файлы

| Файл | Что внутри |
|---|---|
| `styles/theme/fonts.css` | `@font-face` для трёх шрифтов из `fonts/` |
| `styles/theme/tokens.css` | **все** цвета, шрифты, размеры, фоны в виде CSS-переменных `--pg-*` на `:root` |
| `styles/system-styles.css` | раскладка (сетки, размеры, отступы) всех окон; цвета только через токены |
| `styles/theme/newspaper.css` | внешний вид поверх раскладки: рамка окна, типографика, кнопки, шапки, чат |
| `fonts/<шрифт>/OFL.txt` | лицензии шрифтов |

Порядок подключения в `system.json`: `fonts.css` → `tokens.css` → `system-styles.css` → `newspaper.css` → `animations.css`.

**Правило:** в CSS не пишем цвета и шрифты напрямую. Нужен новый цвет — добавляем токен в `tokens.css`
и описываем его здесь. Полупрозрачный вариант токена: `color-mix(in srgb, var(--pg-field) 40%, transparent)`.

## 3. Типографика

| Роль | Токен | Шрифт | Правила |
|---|---|---|---|
| Логотип, газетная шапка | `--pg-font-display` | Ruslan Display | только крупно (от 24px): «Паров-Град», буквица |
| Заголовки, кнопки, подписи | `--pg-font-headline` | Oswald (вариативный 200–700) | ВЕРХНИЙ РЕГИСТР, разрядка `--pg-tracking-caps` (0.08em) |
| Основной текст, значения полей | `--pg-font-body` | Old Standard TT (обычный, курсив, жирный) | обычный регистр; подсказки курсивом |
| Мелкие подписи интерфейса | `--pg-font-ui` | = headline | 10–12px, капителью |

Размеры: `--pg-fs-xs` 10, `--pg-fs-sm` 12, `--pg-fs-md` 14, `--pg-fs-lg` 17, `--pg-fs-xl` 21, `--pg-fs-xxl` 28 (px).

Иерархия листа: логотип (display, ~30–54px) → имя/название (headline 600–700, xl–xxl) →
рубрика раздела h2 (headline 600, lg) → подпись поля (headline 500, sm, muted) → текст (body, md).

### Шрифты и лицензии
Все шрифты поставляются в `fonts/` **без изменений** (не подрезаны и не переименованы), поэтому
условия Reserved Font Name соблюдены. Все три поддерживают кириллицу (включая Ё/ё, №, «», —).

| Шрифт | Папка | Лицензия | Источник |
|---|---|---|---|
| Oswald | `fonts/oswald/` | SIL OFL 1.1 | github.com/google/fonts, `ofl/oswald` |
| Old Standard TT | `fonts/old-standard-tt/` | SIL OFL 1.1 | github.com/google/fonts, `ofl/oldstandardtt` |
| Ruslan Display | `fonts/ruslan-display/` | SIL OFL 1.1 (RFN «Ruslan», «Ruslan Display») | github.com/google/fonts, `ofl/ruslandisplay` |

Если шрифт нужно подрезать (subset) или переконвертировать, по условиям OFL у Ruslan Display нельзя
оставлять имя «Ruslan» — придётся переименовать семейство.

## 4. Компоненты

### Окно (ApplicationV2 / DialogV2)
- Корневые классы окна: `parovgrad` или `ParovGrad` (оба поддерживаются). Без них окно остаётся в стиле Foundry.
- Рамка: бумага `--pg-background-paper`, контур `--pg-brass-dark`, тень `--pg-shadow-window`.
- Шапка: `--pg-background-iron`, латунная полоса 3px снизу, заголовок headline капителью цвета `--pg-brass-light`.
- Внутри окна темовые переменные Foundry (`--color-text-*`, `--input-*`, `--button-*`) перекрашены в токены.

### Газетная шапка листа (`.pg-dossier-header`)
`портрет | строка-кикер + логотип + имя | печать-шестерня`, снизу линейка «толстая + тонкая».
- Кикер (`.pg-dossier-kicker`) — строка между двумя тонкими линейками, текст по краям, ромб `◆` латунью.
- Логотип (`.pg-dossier-brand`) — display, по центру.
- Портрет — «наклеенная фотография»: светлое паспарту, тень, поворот −1.2°, лёгкая сепия.
- Печать (`.pg-dossier-seal`) — латунная шестерня (маска из conic-gradient), внутри инициалы.

### Линейка «толстая + тонкая»
```css
border-bottom: 3px solid var(--pg-rule-strong);
box-shadow: 0 3px 0 var(--pg-paper), 0 4px 0 var(--pg-rule-strong);
```
Используется под шапками листов/окон/диалогов и над подвалом. Готовый класс: `<hr class="pg-rule">`.

### Рубрика раздела (`h2`)
Headline 600, верхний регистр, снизу 2px + 1px линейка. Центрированная рубрика между двумя линейками — `.pg-rubric`.

### Карточка-колонка (характеристики, шкалы, статы оружия, группы эффектов)
Рамка 1px `--pg-rule-strong`, сверху `4px double`, фон — полупрозрачное поле.

### Плашка «ЭКСТРА!» (`.pg-extra`)
Двойная рамка (2px + внутренняя 1px через inset box-shadow), headline 700, капитель с разрядкой 0.12em.
По этому образцу сделаны кнопки «D20» и штамп результата в чате (`.pg-chat-card__result`, повёрнут на −2°).

### Кнопки
- Обычная — латунная пластина: `--pg-background-brass`, рамка `--pg-brass-dark`, headline капителью.
- Главная — типографская: чёрное железо, светлый текст, латунный внутренний контур.
  Применяется автоматически к `data-action` = `save | ok | yes | roll | normal`, к `.default`, к классам
  `pg-spell-builder-apply`, `pg-learn-skill-apply`, `pg-preparation-save`, `pg-rest-apply`, и вручную — `.pg-button--primary`.
- Опасная — текст `--pg-danger` (`.pg-item-delete`, `.pg-effect-delete`, `.pg-chat-button--danger`, `data-action="no"`).
- Размеры кнопок задаёт раскладка (`system-styles.css`); тема меняет только внешний вид.

### Поля ввода
Светлая бумага `--pg-field`, рамка `--pg-field-border`, скругление `--pg-radius` (1px), body-шрифт,
фокус — медный контур 2px. Чекбоксы — `accent-color: var(--pg-brass-dark)`.

### Шкалы ресурсов (`.pg-pool-bar`)
Манометр: латунная оправа со скруглением, деления через 10%, заливка с бликом
(`--pg-mana` для маны, `--pg-copper` для боевых очков).

### Плитка предмета (`.pg-item-tile`)
Рекламный блок в двойной рамке (внешняя `--pg-rule-strong`, внутренняя `--pg-rule` через inset box-shadow).
Название — headline капителью. Бейдж «подготовлен» — негатив (чёрная плашка).

### Диалоги
Передавайте в `DialogV2` классы `["ParovGrad", "pg-dialog"]`. Содержимое — body-шрифт; подвал с кнопками
отделён линейкой «толстая + тонкая». Главной кнопке давайте `action` из списка `yes | ok | save | roll | normal` (или класс `pg-button--primary` в своих шаблонах).

### Карточка чата — «газетная вырезка» (`.pg-chat-card`)
- Карточка сама несёт фон бумаги и двойную рамку, поэтому одинакова в светлой и тёмной теме Foundry.
- `__title` — заголовок номера (headline 700, 19px, по центру), `__subtitle` — курсив под ним,
  шапка отделена линейкой «толстая + тонкая».
- `__meta` — мелкие строки с пунктирной линейкой.
- `__comparison` — врезка с двойной линейкой слева.
- `__result.is-success / .is-failure` — штамп «ЭКСТРА!» цветом патины / киновари.
- Кнопки `.pg-chat-button` — латунные пластины.

### Утилиты для новых шаблонов
`.pg-extra`, `.pg-rule`, `.pg-rubric`, `.pg-columns` (колонки с вертикальной линейкой), `.pg-dropcap` (буквица display-шрифтом).

## 5. Чек-лист для новой доработки

1. Корневой класс окна `ParovGrad` (+ `pg-dialog` для диалогов).
2. Цвета, шрифты, фоны — только `var(--pg-*)`.
3. Заголовки — headline капителью; текст — body; логотип — display только крупно.
4. Разделы отделяются газетными линейками, а не тенями и скруглениями.
5. Металл (латунь/железо) — только для управляющих элементов, не для текста.
6. Новые токены и компоненты дописываются в этот файл.
